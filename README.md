# Description
Ft_trascendence is the last project of the 42 Cpiscine Common-core. We are asked to think, design and develop out very own web application taking on diferent roles. Product Owner, Product Manager, Techincal Lead and Developers.

Our web application is expected to have a frontend, backend and database as well as use a Containerization solution. The git commits must be meaningful and show balance in the team's work distribution. There must be an accessible Privacy Policy and terms of service as well as no Javascript warnings or errors in the browser console.

Some other requirements include:
* A CSS framework or styling solution -> Tailwind.
* Storing credentials (like API keys or environmental variables) in a local, git-ignored .env and provide a .env.example.
* A clear schema and well-defined relations in the database.
* Basic user management with email and password.
* properly validated user inputs in the frontend and backend
